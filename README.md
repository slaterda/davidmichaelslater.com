# David Michael Slater

Website for https://www.davidmichaelslater.com.

This repository contains the complete static website: HTML pages, CSS, JavaScript, and the original book artwork. GitHub Pages publishes the main branch from the repository root. The CNAME file preserves the custom domain, and .nojekyll serves the files without a Jekyll build.

To update the site, edit and commit the relevant HTML, CSS, or JavaScript files. GitHub Pages publishes the new commit automatically. Book search data is in assets/search-index.json.
